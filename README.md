# InStories

Набор бесплатных инструментов для авторов: оформление текста для Фикбука, поиск повторов и сравнение версий главы. Всё работает прямо в браузере, без регистрации.

**Сайт:** https://instories.somee.com

## Что умеет

### Редактор (главная)

Приводит текст к виду, принятому на Фикбуке (теги `<tab>` и `<center>`).

- заменяет короткие тире на длинные «—» и расставляет пробелы после них;
- добавляет отступы в начале абзацев и пустые строки между диалогом и обычным текстом (оба пункта включаются по желанию);
- ставит заглавную букву в начале абзаца и после `.`, `!`, `?`. Продолжение после многоточия, слова автора после реплики («— Привет! — сказал он») и сокращения вроде «т. е.» остаются как есть;
- ставит точку в конце абзаца, если там нет знака препинания;
- приводит разделители сцен (`---`, `* * *`, `~~~`) к `***` и центрирует их;
- сводит несколько пустых строк к одной;
- на выбор: прямые кавычки или «ёлочки», `...` → `…`, удаление лишних пробелов;
- считает слова, символы, абзацы и время чтения;
- запоминает черновик и настройки в браузере, запускается по `Ctrl + Enter`, результат можно скопировать или скачать как `.txt`.

### Поиск повторов

- частые слова с учётом форм («смотрел», «смотрела», «смотрит» считаются вместе);
- одинаковые начала предложений и серии из трёх предложений подряд;
- слова-паразиты с частотой на 1000 слов;
- при нажатии на слово оно подсвечивается по всему тексту.

### Сравнение версий

- сравнение старой и новой версии главы по абзацам, а внутри изменённых абзацев по словам;
- добавленное подсвечивается зелёным, удалённое красным;
- счётчик добавленных и удалённых слов, режим «только изменения».

## Приватность

Весь текст обрабатывается в браузере и никуда не отправляется. Черновик хранится в `localStorage` на твоём устройстве, его можно стереть кнопкой «Очистить». Внешние запросы: шрифты с Google Fonts и Google Analytics (только обезличенная статистика посещений, сам текст в неё не попадает).

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `index.html`, `editor.js`, `home.css` | редактор |

| `diff.html`, `diff.js` | сравнение версий |

Сайт статический: HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск локально

Достаточно любого статического сервера, например:

```bash
python -m http.server 8000
```

После этого открой http://localhost:8000. Лучше не открывать `index.html` двойным щелчком: ссылка «Главная» и страница 404 используют пути от корня сайта.

## Публикация

Файлы кладутся в корень сайта на хостинге (сейчас Somee). `web.config` подключает `404.html` для несуществующих адресов, при этом статус ответа остаётся 404.
